## Source evidence
`publishCheckedStagedOutput` invokes `deleteStagedEntry(candidate)` after detecting a post-move substitution. The helper recursively deletes directories. A foreign directory moved into the candidate path can have unrelated contents erased. The pre-move hook in existing JVM tests reproduces this boundary.

## Scope and acceptance
- Guard failed-publication cleanup by available entry identity; never recursively delete foreign directory trees, symlinks or replacement files.
- Preserve original exceptions and ordinary publication and collision behavior.
- Add focused deterministic JVM regressions for substituted nonempty directory, symlink, regular file and normal publication; run authoritative exact-SHA PR CI.
- Document residual post-check races and the risk that rejected foreign entries can remain at candidate paths. No complete race-freedom claim.
