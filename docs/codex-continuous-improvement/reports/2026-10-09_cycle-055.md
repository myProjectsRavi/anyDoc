# Cycle 055 — Recoverable batch queue URI integrity

**Status:** ACTIVE / INCOMPLETE
**Epic:** `E055`
**Feature:** `F057`
**User Story:** `US-R055-P1-01A`
**Branch:** `codex/anydoc-continuous-improvement`

## Source finding
Direct enqueue accepts arbitrary schemes; preset replay drops blanks and admits non-content URIs; persisted queue recovery rejects them. This violates queue data-integrity and can make otherwise valid stored work unrecoverable.

## Acceptance
Validate URI scheme, presence and all input entries before mutating queue; never drop malformed inputs or replace a valid queue on an invalid preset; preserve ordinary valid content URI workflows. Cover with Robolectric/app JVM tests and authoritative CI.

## Next action
Apply a small, shared input validation seam in BatchQueueRuntimeStore (including atomic preset replay) and test direct/preset enqueue edge cases on the protected feature branch.
