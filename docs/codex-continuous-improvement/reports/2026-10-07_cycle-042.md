## Source finding
`PdfRedactionTool` performs whole-document text extraction twice: once for auto-detect PII and once for irreversible verification. Large PDFs can therefore create avoidable text heap spikes while the PDF document is already resident.

## Scope
- Extract one page at a time for PII auto-detect.
- Verify one page at a time with early exit on the first remaining term.
- Preserve all existing redaction, scrubbing, staging, cancellation, and annotation-verification behavior.
- Add focused deterministic helper tests.
- Validate the exact candidate with authoritative GitHub Actions.
