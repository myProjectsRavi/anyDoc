# AnyDoc Continuous Improvement — Cycle 005

**Status:** ACTIVE / INCOMPLETE  
**Epic:** E005 — Heap-safe PDF page-image export  
**Feature:** F007 — Page-image raster memory budget  
**Current User Story:** US-R005-P2-01A

## Finding

PdfPageImageExporter allocates ARGB_8888 page rasters from PDF page size × caller scale factor without a byte/heap cap. A pathological page or scale can therefore request an unsafe bitmap.

## Existing partial progress

Commit `0004c118cbdbcab88c71333a6cc697b5e8bac5a2` guarantees bitmap recycling through a finally block. GitHub Actions run #186 / API `36382246055` passed that partial candidate.

## Scope

- Add a heap-aware page-raster byte ceiling before Bitmap.createBitmap.
- Preserve normal requested dimensions when safely within budget.
- Downscale oversized rasters proportionally.
- Add focused JVM regression tests.
- Require the standard full branch CI gate.
