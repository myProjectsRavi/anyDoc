## Evidence
`PdfCompareTool.compare` finishes its page loop and opens `FileOutputStream(stagedFile)` before calling `pdfDoc.writeTo(CancellationCheckingOutputStream(...))`. Existing stream checks run on writes, but a cancelled operation can still open the output stream and enter PDF serialization setup. Source-level P2 cancellation responsiveness risk, not a reproduced crash.
