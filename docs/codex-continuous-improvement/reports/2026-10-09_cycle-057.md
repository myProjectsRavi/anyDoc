## Source evidence
`BatchQueueRuntimeStore.moveTask` validates and builds `updated` from a snapshot taken before calling `_state.update`. Its lambda copies that stale list into the latest state, potentially discarding concurrent additions, status changes or queue edits. The terminal-transition fix in Cycle 056 does not address this separate writer.

## Acceptance
Validate task existence, QUEUED status, and target position against the same state that is atomically replaced. Preserve concurrent tasks, status/counters, and queue order; return a failure on invalid or edge moves. Add app JVM regression tests, review the exact diff, and validate exact SHA in authoritative PR CI.
