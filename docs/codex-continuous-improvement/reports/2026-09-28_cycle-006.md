**Feature:** F008 — Transactional page-image and ZIP outputs  
**Current User Story:** US-R006-P1-01A

## Finding

PdfPageImageExporter writes page images and bundle ZIP bytes directly to final user-visible files. Encoding failure, cancellation, or ZIP failure can leave partial output.

## Scope

- Stage all non-ZIP page images before publishing any final file.
- Publish the page-image set only after every page has encoded.
- In ZIP mode, stream each rendered page directly into a staged ZIP and publish only the completed ZIP.
- Preserve collision-safe naming and current result semantics.
- Validate with focused failure-cleanup regression tests and the standard full branch CI gate.
