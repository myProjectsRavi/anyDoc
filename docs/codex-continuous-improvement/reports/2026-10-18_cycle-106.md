## Evidence and scope
`PdfCompareTool.compare` ASCII-sanitizes user output names without bounding the basename length. `withStagedOutputFile` later constructs a `.pdf` destination and may append numeric collision suffixes. Long user names can exceed per-component filename limits. This is source-level risk, not device-measured failure. First inspect existing name validation, collision policy and tests. Add a conservative ASCII length bound preserving ordinary names and allowing suffix space, plus focused host JVM regressions. Validate exact SHA in authoritative draft-PR CI.
