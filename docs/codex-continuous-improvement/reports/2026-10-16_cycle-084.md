## Source evidence
`DocForgeSettingsStore.resolveOutputDirectory` canonicalizes Android-provided public/app storage roots, but returns a configured child folder when `File.isDirectory` is true. `File.isDirectory` follows symbolic links. A symlinked child folder can therefore be returned to a consumer not using `PdfIoUtils` staged output checks, potentially redirecting writes.

## Acceptance criteria
- Refuse to return symlinked configured child folders, including dangling links, on public and fallback roots.
- Preserve legitimate canonicalized platform root aliases and ordinary output folder creation.
- Add deterministic JVM regression tests in the appropriate domain module; do not infer Android device compatibility from JVM tests.
- Obtain authoritative draft-PR GitHub Actions success on the exact combined code/test SHA.
