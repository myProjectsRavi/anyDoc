## Source evidence
`BatchQueueRuntimeStore.markRemainingQueuedAsCanceled()` currently cancels all QUEUED tasks. The foreground service already has the current run's `allowedTaskIds` but does not pass them during cancellation, so tasks enqueued after start can be canceled incorrectly.

## Acceptance
- Cancel only QUEUED task IDs from the active run.
- Preserve later enqueues, RUNNING tasks, terminal statuses, and counters.
- Cover deterministic state cases and concurrent enqueue/cancel in app JVM tests.
- Authoritative PR CI succeeds on the exact code/test SHA.

## Next exact mutation
Change runtime helper to accept active-run IDs, pass them from service, add regression tests and validate the resulting exact SHA. No Cycle 063 code/test mutation at activation. PR #1 draft/unmerged; main untouched.
